# Grid / グリッド（格子状の一覧）

- id: `grid`  URL: https://uizukan.dev/entry/grid/

- 別名: Photo Grid, Grid View, Collection View, Tile Grid
- 呼び名: Material 3=該当なし（Layout の Grid。部品ではない） / Material 2=Image list（旧称 Grid list） / Android (Compose)=LazyVerticalGrid / iOS (HIG)=Collections / SwiftUI=LazyVGrid / Grid / Web=display: grid（CSS Grid）/ Grid（WAI-ARIA パターン） / Flutter=GridView / SliverGrid

**説明**: 同じ大きさのセルを格子状に並べる。列数は画面幅で変える（レスポンシブ）。高さがバラバラなら staggered grid。

**使いどころ**: 写真・商品・アルバムなど、画像が主役の一覧。文字が主役ならリスト。
