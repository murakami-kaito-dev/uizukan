# Avatar / アバター（丸いプロフィール画像）

- id: `avatar`  URL: https://uizukan.dev/entry/avatar/
- 種別: 表示 / Data Display
- 別名: Profile Picture, User Icon, Circle Avatar, Avatar Group
- 呼び名: Material 3=該当なし（List item の leading avatar として登場。独立部品ではない） / Material 2=該当なし（List item の avatar） / Android (Compose)=該当なし（Image + Modifier.clip(CircleShape)） / iOS (HIG)=該当なし（Image view を円形に） / SwiftUI=Image + .clipShape(Circle()) / Web=<img>（Avatar。alt 必須） / Flutter=CircleAvatar
- Flutter: `CircleAvatar`
- 関連: badge, list_tile, chat_bubble

**説明**: 円形のユーザー画像。画像未設定時はイニシャルや人型アイコンを背景色付きで表示する。右下にオンライン状態の点を重ねることもある。

**使いどころ**: ユーザーを表すあらゆる場所（コメント、チャット、メンバー一覧）。

**AI への伝え方（日本語）**: 直径 40dp の Avatar を作って。画像があれば表示、なければ名前のイニシャルを primaryContainer 背景で。右下にオンラインの緑の点を重ねて。

**Prompt (English)**: Create a 40dp Avatar: show the image if available, otherwise the name's initials on a primaryContainer background, with a green online dot at the bottom-right.
