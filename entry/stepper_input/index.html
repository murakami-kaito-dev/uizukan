**使いどころ**: 小さな整数（1〜10 程度）の選択。範囲が広いなら Slider や数値入力。

**AI への伝え方（日本語）**: 商品数量を選ぶ Quantity Stepper（− 数字 ＋）を作って。1未満にならず、上限は在庫数。値が変わるたびに軽い触覚を鳴らして。

**Prompt (English)**: Create a Quantity Stepper (− number +) for a product. Never go below 1; cap at stock count; play a light haptic on each change.
