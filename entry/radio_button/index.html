# Radio Button / ラジオボタン

- id: `radio_button`  URL: https://uizukan.dev/entry/radio_button/
- 種別: 表示 / Inputs & Selection
- 別名: Radio Group, Option Button, Radio List Tile
- 呼び名: Material 3=Radio button / Material 2=Radio button（Selection controls） / Android (Compose)=RadioButton / iOS (HIG)=該当なし（iOS 標準には無い。チェックマーク付き List か Picker で代替。macOS は Radio button） / SwiftUI=Picker + .pickerStyle(.radioGroup)（macOS）/ .inline / Web=<input type="radio"> / Flutter=Radio / RadioListTile

- 関連: checkbox, segmented_button, dropdown_menu

**説明**: 同じ groupValue を共有する丸い選択肢。1つを選ぶと他は自動で外れる。

**使いどころ**: 2〜5個の排他的選択（配送方法、支払い方法）。候補が多ければ Dropdown、2択なら Segmented Button も検討。

**AI への伝え方（日本語）**: 支払い方法（クレジットカード／コンビニ／銀行振込）を RadioListTile で1つだけ選べるようにして。

**Prompt (English)**: Let the user choose one payment method (Credit card / Convenience store / Bank transfer) using RadioListTiles.
