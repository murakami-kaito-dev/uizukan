# Outlined Text Field / アウトライン付きテキストフィールド

**説明**: 枠線（outline）で囲まれた入力欄。フォーカスすると枠が primary 色になり、ラベルが枠線の切れ目に小さく浮き上がる（floating label）。ヒント・エラー文・文字数カウンタを下に出せる。

**使いどころ**: フォーム全般。背景が白っぽく Filled だと目立たないとき。
