概要

選択中のタブに下線インジケータが付き、内容を横スワイプで切り替えられる。タブが多いときは横スクロール（isScrollable）。

使いどころ

# Tabs / タブ（上部タブ）

- id: `tab_bar`  URL: https://uizukan.dev/entry/tab_bar/
- 種別: 表示 / Navigation
- 別名: Tab Bar, Top Tabs, Scrollable Tabs, Tab Layout
- 呼び名: Material 3=Tabs（Primary / Secondary） / Material 2=Tabs（Fixed / Scrollable） / Android (Compose)=PrimaryTabRow / SecondaryTabRow / ScrollableTabRow + Tab / iOS (HIG)=該当なし（Segmented control で代替。iOS の Tab bar は画面下の別物） / SwiftUI=該当なし（Picker(.segmented) か TabView(.page)） / Web=Tabs（WAI-ARIA パターン。role="tablist"） / Flutter=TabBar + TabBarView + DefaultTabController
