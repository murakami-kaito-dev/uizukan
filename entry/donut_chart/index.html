# Donut Chart / ドーナツグラフ

- id: `donut_chart`  URL: https://uizukan.dev/entry/donut_chart/
- 種別: 表示 / Data Display
- 別名: Doughnut Chart, Ring Chart, Pie Chart, Sector Chart
- 呼び名: Material 3=該当なし（Data visualization の指針のみで部品は無い） / Material 2=該当なし（Data visualization の指針のみ） / Android (Compose)=該当なし（Canvas.drawArc で自作） / iOS (HIG)=Charts（Swift Charts の扇形） / SwiftUI=Chart + SectorMark(angle:innerRadius:) / Web=該当なし（SVG の円弧や Chart.js の doughnut で自作） / Flutter=自作（CustomPainter + Canvas.drawArc）

**説明**: 円グラフの真ん中をくり抜いた形。区分ごとに色を変えた弧を時計の 12 時から順に並べ、弧の長さで割合を示す。空いた真ん中に合計や使用率を大きく書けるのが円グラフとの違い。

**使いどころ**: ストレージの使用量、支出の内訳、時間の使い方など「全体のうち何がどれだけか」を 2〜6 区分で見せるとき。区分が多い・値が近いときは棒グラフのほうが読みやすい。色だけで区別させず凡例（Chart Legend）を必ず添える。

**AI への伝え方（日本語）**: ストレージ使用量を Donut Chart で見せて。写真・アプリ・書類・その他の 4 色の弧を 12 時から順に並べ、真ん中に「43.5 / 64 GB」。表示時に弧が伸びるアニメーション付きで。

**Prompt (English)**: Show storage usage as a Donut Chart: four colored arcs (Photos, Apps, Documents, Other) starting at 12 o'clock, with "43.5 / 64 GB" in the center, and animate the arcs growing in on appear.
