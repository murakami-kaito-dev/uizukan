# Full-screen Dialog / 全画面ダイアログ（モーダル画面）

- id: `full_screen_dialog`  URL: https://uizukan.dev/entry/full_screen_dialog/

**説明**: 通常の push（右から）ではなく下から出てくる画面。App Bar の左が「×（閉じる）」、右が「保存／完了」になるのが作法。

**使いどころ**: 新規作成・編集・複数項目の入力など「一連の作業を終えてから戻る」画面。

**AI への伝え方（日本語）**: 「新規投稿」を Full-screen Dialog として開いて。下からせり上がるアニメーションで、左上に ×、右上に「投稿」ボタンを置いて。

**Prompt (English)**: Open "New post" as a Full-screen Dialog: it slides up from the bottom, with an × at the top-left and a "Post" button at the top-right.
