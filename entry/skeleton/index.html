# Skeleton Screen / スケルトンスクリーン

- id: `skeleton`  URL: https://uizukan.dev/entry/skeleton/
- 種別: 表示 / Feedback & Status
- 別名: Skeleton Loader, Shimmer Placeholder, Content Placeholder, Ghost Element
- 呼び名: Material 3=該当なし（Motion の Skeleton loaders として言及のみ） / Material 2=該当なし（M2 に無い） / Android (Compose)=該当なし（Brush + Modifier.background で自作） / iOS (HIG)=該当なし（iOS 標準には無い） / SwiftUI=.redacted(reason: .placeholder) / Web=該当なし（Skeleton screen） / Flutter=自作 / skeletonizer / shimmer パッケージ
- Flutter: `自作 / skeletonizer / shimmer パッケージ`
- 関連: shimmer, circular_progress, crossfade

**説明**: テキストや画像の位置に灰色の四角を置く。止まった箱だけでもスケルトンだが、光が流れるシマー（Shimmer）と組み合わせることが多い。スピナーより「もうすぐ出る」感が強く、体感が速い。

**使いどころ**: フィード・一覧・詳細画面の初回読み込み。短時間（300ms 未満）なら不要。

**AI への伝え方（日本語）**: フィードの読み込み中は、カードと同じ形のグレーの Skeleton を 3 枚出して。左から右に光が流れる shimmer アニメーション付きで。

**Prompt (English)**: While the feed loads, show 3 gray Skeleton cards shaped like the real cards, with a left-to-right shimmer animation.
