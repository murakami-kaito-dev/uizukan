# Extended FAB / 拡張 FAB（ラベル付き FAB）

- id: `extended_fab`  URL: https://uizukan.dev/entry/extended_fab/

**説明**: 通常の FAB にテキストを添えた横長版。スクロールで通常 FAB に縮む（collapse）動きと組み合わせることが多い。

**使いどころ**: アイコンだけでは意味が伝わりにくい主要操作（例：「新しいメモ」「ルートを開始」）。

**Prompt (English)**: Add an Extended FAB with an icon and a "Create" label at the bottom-right. When scrolling down, collapse it into a regular icon-only FAB.
