ステートレイヤー

state layer

押したりホバーしたりした部品の上に重ねる、半透明の色の膜。

説明

Material 3 で、部品の状態を伝えるために上に重ねる半透明の色のこと。状態ごとに別の色を用意する代わりに、同じ色を薄く重ねて表す。 濃さは決まっていて、ホバーが 8%、フォーカスと押している間が 10%、ドラッグ中が 16%。重ねる色は、その部品の文字やアイコンの色（primary の上なら onPrimary）。 押した所から広がる波紋（Ripple）は、このステートレイヤーに動きを付けたもの。
