共有要素の遷移

shared element transition

画面をまたいで同じものが移動・拡大する遷移。

説明

2 つの画面に同じ要素があるとき、遷移の間その要素が位置と大きさを変えながら移動する見せ方。一覧のサムネイルが、そのまま詳細画面の大きな画像になって着地する動きが典型。 「別の画面に来た」ではなく「同じものを大きく見ている」と感じられ、一覧と詳細のつながりが切れない。Flutter では Hero、SwiftUI では matchedGeometryEffect と呼ぶ。
