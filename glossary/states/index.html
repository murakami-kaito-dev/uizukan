状態（ステート）

state / enabled・disabled・pressed・selected

部品が取りうる「いまの様子」の決まった名前。無効・押している間・選択中など。

説明

ボタンや入力欄は、同じ部品でも状況によって見た目が変わる。その状況に付いた名前が状態。 ・enabled … 普通に押せる ・disabled … 無効。押せない（薄く表示する） ・pressed … 押している間 ・hovered … マウスを重ねている ・focused … キーボードの入力先になっている ・selected … 選ばれている（タブ・チップ・スイッチのオン） AI に頼むときは「disabled のときは文字を薄く」「pressed の間だけ少し縮める」のように、状態の名前で言うと正確に伝わる。見落としやすいのは disabled と、読み込み中・エラーの状態。
