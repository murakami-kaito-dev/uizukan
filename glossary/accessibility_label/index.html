アクセシビリティラベル

accessibility label / 読み上げ用の名前

画面には出ないが、読み上げ機能が声に出す、部品の名前。

説明

画面を見ずに使う人のための読み上げ機能（iOS の VoiceOver、Android の TalkBack）が、その部品に触れたときに読み上げる名前。 文字のあるボタンは、その文字が読まれるので何もしなくてよい。必要なのは、アイコンだけのボタンと、意味のある画像。付けないと「ボタン」としか読まれず、何のボタンか分からない。 名前は「ゴミ箱」のような見た目ではなく、「削除」のように何が起きるかを書く。AI に頼むときは「アイコンだけのボタンには読み上げ用の名前を付けて」と添える。Flutter では tooltip か Semantics(label:)、SwiftUI では .accessibilityLabel。
