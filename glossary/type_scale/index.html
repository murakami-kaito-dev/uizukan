タイプスケール

type scale / テキストスタイル

文字の大きさと太さを、役割ごとの名前で決めた一覧。

説明

「見出し」「本文」「ボタンの文字」のように、役割ごとに大きさ・太さ・行の高さを決めた、文字の型の一覧。数字（17pt の太字）ではなく、名前で指定する。 Material 3 は display・headline・title・body・label の 5 種に、それぞれ large・medium・small があり、全部で 15 種。たとえば titleLarge は 22、bodyLarge は 16、labelLarge は 14。 iOS はテキストスタイルと呼び、Large Title（34）・Title 1〜3・Headline・Body（17）・Callout・Subhead・Footnote・Caption がある。 AI に頼むときは「見出しは titleLarge、補足は bodySmall」のように名前で言うと、画面ごとに大きさがばらつかない。
