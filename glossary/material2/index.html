Material 2

マテリアル 2 / M2

Material Design の 1 つ前の版（2018〜2021）。部品の旧名の出どころ。

説明

Google のデザインシステム Material Design の 2 番目の版。2018 年から 2021 年まで標準だった。 この図鑑で「Material 2」の行に書いてある名前は、その頃の呼び名。たとえば Raised Button（→ Elevated Button）、Flat Button（→ Text Button）、Bottom Navigation Bar（→ Navigation Bar）は Material 3 で改名された。古い記事や Stack Overflow の回答、Flutter の旧 API 名にはこの版の名前が残っているので、検索で見つけた名前がどちらの版かを見分けるために併記している。 見た目の違いは、影を多用する（Material 2）か、色の濃さで面を区別する（Material 3）か、角丸が小さい（4dp 前後）か大きい（12dp 以上）か。
