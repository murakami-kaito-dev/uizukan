追加のしかた ①

Claude Code

1. ターミナルで次の 1 行を実行します（どのフォルダーからでも同じ。--scope user で、すべてのプロジェクトで使えます）。

claude mcp add --transport http --scope user uizukan  --header "Authorization: Bearer "

2. Claude Code を開き直し、/mcp と打ちます。一覧に uizukan が出て「connected」になっていれば完了です。ターミナルで claude mcp list でも確かめられます。

追加のしかた ②

Codex（OpenAI）

1. ターミナルで次のコマンドを実行します。Codex の設定ファイル ~/.codex/config.toml の最後に UI図鑑の設定を書き足します（ファイルが無ければ作られます）。

mkdir -p ~/.codex && cat >> ~/.codex/config.toml <<'EOF'

[mcp_servers.uizukan]
url = ""
http_headers = { "Authorization" = "Bearer " }
EOF

2. Codex を開き直します。すでに [mcp_servers.uizukan] がある場合は、2 つにならないよう古い方を消してください。

追加のしかた ③

Cursor

1. ~/.cursor/mcp.json（すべてのプロジェクト用。プロジェクトだけなら .cursor/mcp.json）を開き、次の内容にします。すでに他の MCP サーバーがある場合は、"mcpServers" の中に "uizukan" の部分だけを足します。

{
  "mcpServers": {
    "uizukan": {
      "url": "",
      "headers": {
        "Authorization": "Bearer "
      }
    }
  }
}

2. Cursor の設定の MCP の画面で、uizukan が有効（緑）になっていれば完了です。

MCP を使わないとき

Pro 版スキル（Claude Code）

詳細プロンプトと Flutter コードを全項目分まとめた Claude Code のスキルです。MCP と違い手元に置くファイルなので、項目が増えたときは同じボタンで取り直してください。MCP を追加した場合は不要です。

1. 下のボタンで zip をダウンロードします（キーを確かめてから渡します）。

2. ターミナルで次を実行し、Claude Code のスキルの場所に展開します（すべてのプロジェクトで使えます）。無料版の ui-zukan を入れている場合は、Pro 版に置き換わります。

mkdir -p ~/.claude/skills && unzip -o ~/Downloads/ui-zukan-pro-skill.zip -d ~/.claude/skills/

3. Claude Code を開き直すと使えます。中の references/*.md は Markdown なので、他の AI ツールに読ませることもできます。再配布はしないでください。

使い方

ふだんどおり AI に頼むだけ

特別な書き方は要りません。UI の見た目や動きが関わる頼みごとをすると、AI が UI図鑑で名前を調べ、詳細プロンプトとコードを読んでから実装します。確実に使わせたいときは「UI図鑑で調べてから」と添えてください。

たとえば

あなた設定画面の通知のオンオフ、押したら軽くブルッとさせて。UI図鑑で調べてから実装して

AIfind_ui → Toggle Switch（トグルスイッチ）＋ Haptic on Toggle を見つける

AIget_ui で詳細プロンプトと Flutter コードを読み、寸法・切り替えの時間・振動の種類に合わせて実装

ほかにも「この画面の下から出るやつの正式な名前は？」「Toggle Switch と触覚を 1 つの指示文にまとめて」のように、名前を聞く・指示文を作らせる使い方もできます。

うまくいかないとき

確かめること

ヘッダーは Authorization: Bearer キー の形です。Bearer とキーの間に半角スペースが 1 つ要ります。キーの前後に余計な空白が入っていないかも確かめてください。
追加したあと、AI ツールを開き直してください（開いたままだと読み込まれません）。
キーが正しくないと、名前を探す（無料の範囲）だけが動き、詳細プロンプトとコードの代わりに Pro の案内が返ります。
